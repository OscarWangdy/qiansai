\section{尺寸预算与底盘布局}

Raspberry Pi 5 的 PCB 外形为 85 mm $\times$ 56 mm，安装孔距为 58 mm $\times$ 49 mm，孔径 2.7 mm\cite{pi5mechanical}。Hailo 载板、散热器和相机排线会扩大实际包络，因此不能只按裸板尺寸开孔。

\subsection{收到货后的最低验收}

\begin{enumerate}
\item 拍摄包装、板卡版本、丝印、接口和配件；保存商品页与数据手册。
\item 电机悬空低占空比试转，确认左右方向、A/B 相波形和每圈计数；不得长时间堵转。
\item MDD10A 先用限流电源单路测试，再连接两台电机；验证失控时默认 PWM 为 0。
\item IMU 静止校零并旋转检查轴向；ToF 逐只修改地址、记录近/远距离和暗色目标表现。
\item 稳压模块空载调压后加电子负载；记录电压跌落、纹波、温升与 Pi 欠压标志。
\item 安装后检查线束不会卷入车轮，急停可直接切断动力，树莓派失联时 FPGA 仍可停车。
\end{enumerate}
